# Velvet Circuit Supply

A fictional dark editorial storefront for mechanical keyboard and desktop accessories. The public demo uses sample prices and stock. Checkout needs no login, address or payment.

[Open the demo](https://a-feraci.github.io/velvet-circuit-supply/) · [Business brief, wireframes and technical decision](docs/project-notes.md) · [Portfolio handoff](docs/portfolio-handoff.md) · [Changelog](CHANGELOG.md)

## Run locally

Open `index.html` in a modern browser or run `python -m http.server 8000` from the repository root. The Pages source is the `main` branch root. There are no runtime packages or environment variables.

To try the core flow, open Orbit Veil Desk Mat, select Compact, add it to the bag, change the quantity and preview express shipping. Fallen Star Artisan demonstrates out-of-stock handling.

The product gallery uses original generated imagery. The bag persists SKU quantities in the visitor's browser when storage is available.
